Search recorded entries from Today or Calendar with local note-text search and
inclusive date-range, symptom, and mood filters. Results appear newest first and
open the shared editor; saving or deleting refreshes the current results without
resetting filters. Discreet mode hides details in result previews.

Queries stay in screen memory and are not saved or sent to a search service. No
database or plaintext GitHub sync format changes are introduced.
